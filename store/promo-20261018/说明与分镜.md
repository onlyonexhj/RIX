# X AI 回复助手 · 横屏产品介绍

- 1920×1080，30fps，40 秒，H.264 / AAC。
- 中文字幕与程序合成背景音乐，无旁白。
- 使用当前扩展界面；推文、模型回复和 API Key 均为演示数据。
- 操作止于回填，未连接个人 X 登录态，未点击发布。

## 分镜

00–04 秒：想好好回复，不必每次从空白开始。
04–11 秒：点开回复，AI 自动生成多条候选。
11–17 秒：选中喜欢的一条，一键填入，再由你决定发布。
17–23 秒：多种回复风格，找到适合这条推文的表达。
23–29 秒：自定义人设与提示词，让表达更贴近你。
29–36 秒：多家模型自由选，API Key 保存在浏览器本地。
36–40 秒：X AI 回复助手，把想说的话写出来。
