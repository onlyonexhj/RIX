```text
在 X（Twitter）时间线点击回复气泡打开发帖弹层时，本扩展会自动读取你正在回复的推文，调用 AI 生成多条候选回复，点一下即可回填到输入框。

【主要功能】

· 自动识别回复弹层
点开回复气泡后，AI 面板自动出现，并提取被回复推文的作者、正文与发布时间。

· 一次生成多条候选
可生成 1–5 条候选，各条切入角度不同，不是同一句话的改写。点任一条即写入发帖框，字符计数与发帖按钮正常联动。

· 内置 8 种回复风格
幽默、专业、犀利、共情、争议、抽象、翻译润色、嘲讽。默认风格可在设置页调整。

· 流式输出
边生成边显示，第一条约 1 秒即可见，不必等全部生成完。状态栏会显示首字延迟与总耗时。

· 提示词完全可配置
system / user 模板均可自定义，支持 12 个变量插值（推文正文、作者、条数、风格、语言等），拼错变量会实时提示。改完可点「预览渲染结果」查看模型实际收到的内容，不消耗 API 额度。

· 支持多家服务商
智谱 GLM、DeepSeek、OpenAI、Claude、Kimi、OpenRouter，以及任何 OpenAI 兼容接口（含本地 Ollama / vLLM）。

· 面板可拖拽
按住标题栏即可移动到任意位置；默认自动贴在发帖弹层左侧，不会遮挡输入框与发帖按钮。双击标题栏可复位。

· 长任务有反馈
生成中显示实时计时，超过 30 秒出现进度条，随时可点「中止」。失败后按钮变为「重试」，不会卡死。

【隐私说明】

API Key 仅保存在浏览器本地（chrome.storage.local），不会上传到任何服务器。本扩展不设服务端，所有请求由你的浏览器直接发往你自行配置的模型服务商。扩展不会收集、存储或分析你的浏览记录，也不会将推文内容用于生成回复以外的任何用途。

【使用方法】

1. 点浏览器工具栏的扩展图标，进入「全部设置」；
2. 选择服务商预设，填写你持有的 API Key，点「测试连接」确认可用；
3. 打开 X 时间线，点任意推文的回复气泡，AI 面板即自动出现；
4. 点「生成回复」，从候选里挑一条点一下，内容自动填入输入框，可直接发布。

需要配合你自己持有的 AI 服务商 API Key 使用。建议同时开启「流式输出」（默认已开启）以获得最快的响应体验。
```

## 二、隐私惯例（Privacy practices）— 单独一个标签页

### 单一用途说明（Single purpose）

```text
本扩展的单一用途是：在 X（Twitter）上，针对用户正在回复的推文生成 AI 候选回复，并将用户选中的回复写入发帖输入框。除此之外不用于任何其他目的。
```

### 权限理由（Permission justification）

逐条对应填写：

**`storage`（存储）**
```text
用于在浏览器本地保存用户的 AI 服务商配置，包括 API Key、Base URL、模型名、默认风格与条数等偏好设置。所有数据仅存储于浏览器本地的 chrome.storage.local，不会同步或上传到任何服务器。
```

**`proxy`（代理）**
```text
用于实现设置页中的「网络与代理」选项。部分用户的网络环境下，访问 AI 接口走系统代理会明显变慢，该权限允许用户选择「AI 接口直连」或「指定代理服务器」来改善。默认模式为「跟随系统默认」，此模式下扩展不会修改浏览器的任何代理设置；用户主动选择其他模式时，扩展会明确提示影响范围并要求二次确认，且提供「恢复默认」随时交还控制权。
```

**主机权限 — `x.com` / `twitter.com`**
```text
用于在 X 页面注入内容脚本，以识别用户点开的回复发帖弹层、读取被回复推文的正文，以及将生成的候选回复写入发帖输入框。
```

**主机权限 — 各 AI 服务商域名**
```text
用于让后台 service worker 直接向用户自行配置的模型服务商（如 open.bigmodel.cn、api.deepseek.com、api.openai.com 等）发送 API 请求。content script 的跨域请求会被 X 页面的 CSP 拦截，因此必须由后台代理发出。
```
