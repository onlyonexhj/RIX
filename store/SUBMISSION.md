## 二、隐私惯例（Privacy practices）— 单独一个标签页

### 单一用途说明（Single purpose）

```text
本扩展的单一用途是：在 X（Twitter）上，针对用户正在回复的推文生成 AI 候选回复，并将用户选中的回复写入发帖输入框。除此之外不用于任何其他目的。
```

### 权限理由（Permission justification）

逐条对应填写：

**`storage`（存储）**
```text
用于在浏览器本地保存用户的 AI 服务商配置，包括 API Key、Base URL、模型名、默认风格与条数等偏好设置。所有数据仅存储于浏览器本地的 chrome.storage.local，不会同步或上传到任何服务器。
```

**`proxy`（代理）**
```text
用于实现设置页中的「网络与代理」选项。部分用户的网络环境下，访问 AI 接口走系统代理会明显变慢，该权限允许用户选择「AI 接口直连」或「指定代理服务器」来改善。默认模式为「跟随系统默认」，此模式下扩展不会修改浏览器的任何代理设置；用户主动选择其他模式时，扩展会明确提示影响范围并要求二次确认，且提供「恢复默认」随时交还控制权。
```

**主机权限 — `x.com` / `twitter.com`**
```text
用于在 X 页面注入内容脚本，以识别用户点开的回复发帖弹层、读取被回复推文的正文，以及将生成的候选回复写入发帖输入框。
```

**主机权限 — 各 AI 服务商域名**
```text
用于让后台 service worker 直接向用户自行配置的模型服务商（如 open.bigmodel.cn、api.deepseek.com、api.openai.com 等）发送 API 请求。content script 的跨域请求会被 X 页面的 CSP 拦截，因此必须由后台代理发出。
```
