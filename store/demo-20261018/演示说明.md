# X AI 回复助手 · 产品操作演示

- 时长：60 秒。1920×1080，30fps，H.264 / AAC。
- 中文字幕、背景音乐，无旁白。
- 使用当前扩展代码与虚构推文；模型回复、账号及 API Key 均为演示数据。
- 所有网络请求在本地拦截，操作止于回填。

## 演示流程

00.0–03.0 秒：X AI 回复助手 · 从推文到回复的完整演示
03.0–05.3 秒：点击推文下方的回复按钮。
05.3–08.2 秒：面板自动读取上下文，逐条显示生成的候选。
08.2–11.0 秒：候选回复生成完成，挑选你喜欢的一条。
11.0–13.2 秒：点击候选，即可填入回复输入框。
13.2–18.0 秒：你可以继续修改内容，再自行决定是否发布。
18.0–23.0 秒：切换到幽默风格，重新生成另一种表达。
23.0–28.0 秒：也可以选择专业风格，让回复更贴近当前语境。
28.0–31.5 秒：按需要调整回复条数和输出语言。
31.5–33.8 秒：生成一条英文候选，确认内容。
33.8–35.0 秒：点击候选，填入新的回复。
35.0–38.2 秒：生成过程中，可以随时中止。
38.2–41.0 秒：需要继续时，再点一次生成回复。
41.0–48.0 秒：在设置中选择模型服务，填写自己的 API Key。
48.0–51.8 秒：设置人设与提示词，让回复更符合你的表达习惯。
51.8–55.0 秒：预览提示内容，确认设置是否符合预期。
55.0–60.0 秒：X AI 回复助手，让表达更轻松。
