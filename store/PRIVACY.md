# 隐私政策 — RIX

**最近更新日期：2026 年 10 月 17 日**

本隐私政策适用于 Chrome 扩展「RIX」（以下简称"本扩展"）。安装或使用本扩展，即表示你同意本政策所述的数据处理方式。

## 1. 我们收集什么数据

**本扩展不设任何服务端，不建立用户账号，不收集任何可识别你个人身份的信息。**

本扩展会在你的浏览器本地（`chrome.storage.local`）保存你自行填写的配置信息，包括：

- AI 服务商的 Base URL 与模型名称
- 你的 API Key
- 界面偏好（默认风格、生成条数、输出语言等）
- 你自定义的提示词模板

这些数据仅保存在你的设备上，不会同步到任何服务器，也不会发送给扩展开发者。

## 2. 推文内容如何处理

当你在 X（Twitter）上点开回复气泡时，本扩展会读取**你正在回复的那条推文**的以下内容：

- 推文正文
- 推文作者的显示名称与 handle
- 推文发布时间

这些内容的**唯一用途**是作为上下文，发送给你在设置页自行配置的 AI 模型服务商，用于生成回复候选。

除该 AI 服务商外，本扩展不会将上述内容发送给任何第三方。本扩展不记录、不存储、不分析你的浏览历史，也不会将推文内容用于生成回复以外的任何目的。

## 3. 数据传输

本扩展产生的网络请求只有两类：

1. **发往你自行配置的 AI 模型服务商**（如智谱 GLM、DeepSeek、OpenAI、Anthropic 等），内容为你所回复推文的上下文与你的提示词模板。请求使用你在设置页填写的 API Key 鉴权。
2. 无其他对外请求。本扩展不包含任何统计、埋点、广告或远程配置逻辑。

你需要自行了解并信任你所选择的 AI 服务商的数据处理政策。本扩展不对第三方服务商的行为负责。

## 4. API Key 的安全

你的 API Key 仅保存在浏览器本地的 `chrome.storage.local` 中。由于 Chrome 扩展的内容脚本与页面脚本运行在隔离环境，该 Key 不会暴露给 X 页面或其他网站的 JavaScript。

## 5. 代理设置

本扩展提供可选的「网络与代理」配置，用于在 AI 接口访问缓慢时调整网络路径。默认模式清除本扩展的代理覆盖，使用浏览器原有配置。当你应用其他模式时，扩展会先明确提示影响范围并要求确认；尚未应用的代理表单不会自动保存。你随时可以点「恢复默认」交还控制权；在扩展设置中停用或恢复全部默认设置也会清除本扩展的代理覆盖。

## 6. 数据保留与删除

卸载本扩展即可删除其保存在本地的全部配置数据。本扩展不持有你的任何数据的副本，因此无法访问、提供或删除已传输至第三方 AI 服务商的数据——如需删除，请直接联系对应的服务商。

## 7. 儿童隐私

本扩展不面向 13 岁以下儿童，也不会主动收集任何人的个人信息。

## 8. 政策变更

如本政策发生变更，我们会更新本页面顶部的"最近更新日期"。重大变更会在扩展的新版本说明中告知。

## 9. 联系方式

如对本隐私政策有任何疑问，请通过 Chrome 网上应用店内的支持邮箱与我们联系。
